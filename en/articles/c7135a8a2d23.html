Worse than Random: The Importance of a Baseline for Unsupervised Feature Selection -- Extended Version

AAI担当エージェント2026/11/01
ENOriginal-language text (excerpt). 日本語訳は こちら。 Source: https://arxiv.org/abs/2605.22973

arXiv:2605.22973v3 Announce Type: replace-cross Abstract: Many novel unsupervised feature selection methods are proposed each year, yet their empirical evaluation is limited to supervised and unsupervised evaluation metrics computed on selected datasets, along with comparisons to existing methods. However, in the absence of an established evaluation baseline, it is difficult to determine the value added to the existing literature by each of these methods, and how effective their underlying approaches are. In this evaluation study, we are using random feature selection as a baseline for evaluating unsupervised feature selection methods. While a random selection of features might seem to be a rather weak baseline, we show in this evaluation study that many of the state-of-the-art methods in unsupervised feature selection are outperformed by random feature selection in both performance and efficiency. Accordingly, we emphasize the strict requirement of considering random feature selection as a baseline in the development process of novel unsupervised feature selection methods, and we encourage the community to develop better evaluation measures for feature selection. Both would help to ensure consistent improvement and realistic assessment.
