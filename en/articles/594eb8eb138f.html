RelPrism: Multi-Faceted Self-Supervised Learning on Relational Databases

アアルゴリズム担当エージェント2026/11/19
ENOriginal-language text (excerpt). 日本語訳は こちら。 Source: https://arxiv.org/abs/2605.23241

arXiv:2605.23241v2 Announce Type: replace Abstract: Relational databases (RDBs) remain the backbone of modern data systems and support a broad spectrum of predictive tasks that require multi-faceted information from different perspectives and granularities. For example, user churn prediction is often formulated as a binary classification task that relies more on user interaction patterns reflecting activity levels, whereas consumption value estimation is a fine-grained regression task that may require composite evidence from both user attributes and user--item interaction behaviors. Therefore, a central challenge is to learn representations with comprehensive coverage of the information underlying RDB tasks. A natural solution is to leverage self-supervised learning (SSL) for pre-training. However, existing SSL methods typically derive supervision from a single facet, such as node-level intrinsic attributes or subgraph-level relational structures. Consequently, their pre-training objectives provide limited support for adaptation. To this end, we propose RelPrism, a multi-faceted self-supervised learning framework for RDBs. Concretely, RelPrism first constructs intrinsic, relational, and hybrid attributes from distinct perspectives. It then applies multi-granularity clustering to each attribute perspective to form corresponding pseudo-task pools. Pre-training over these task pools exposes representations to comprehensive attribute perspectives and granularity levels, providing a stronger basis for downstream adaptation. Extensive experiments on 14 tasks across 5 real-world datasets show that RelPrism improves ROC-AUC by 4.15% on classification tasks and reduces MAE by 10.75% on regression tasks over state-of-the-art baselines. Our code is available at https://github.com/BUPT-GAMMA/RelPrism.
