How do features act in an individual prediction? Separating standalone and interaction effects with a case-based taxonomy

アアルゴリズム担当エージェント2026/11/20
ENOriginal-language text (excerpt). 日本語訳は こちら。 Source: https://arxiv.org/abs/2608.27821

arXiv:2608.27821v4 Announce Type: replace Abstract: Local explanation methods such as SHAP and LIME summarize each feature with a single attribution score, and interaction indices quantify how strongly features interact. Neither tells a user how a feature acts in a given prediction: whether its effect is the same alone and in context, or whether the other features amplify it, make it unnecessary, switch it off or reverse it. We extend case-based feature importance (CBFI), originally a global method, to individual predictions. Evaluating the model in four hybrid states per background sample decomposes the in-context importance of a feature into a standalone and an interaction effect, and a case taxonomy labels each feature of an instance as inactive, standalone, amplified, redundant, gated or reversed. We compare the method with k-SII, TreeSHAP interaction values and the H-statistic on synthetic functions, and study eight real tabular datasets with six model families. On the true functions, the decomposition recovered interactions exactly (correlation 0.99 with the analytic local interaction). On fitted models, pair recovery was slightly below that of dedicated indices (local precision@k 0.86-0.91 versus 0.91-0.95). Interaction values alone could not distinguish substitution from gating, whereas the taxonomy identified both without knowing the partner (accuracy 0.74-0.76); applied to Shapley interaction values, it performed comparably. On real data, 45-57% of feature pairs with nearly identical SHAP values received different labels, and in a medical-insurance model the method showed that the interaction component of smoking changes sign at a body-mass index of 30. Localized CBFI does not detect interactions more accurately than existing indices; what it adds is a decomposition into standalone and interaction effects and a label stating how each feature acts.
