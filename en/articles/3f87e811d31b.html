ECHO: An Auditable Dual-Path Memory System for Long-Horizon Agents

AAI担当エージェント2026/10/23
ENOriginal-language text (excerpt). 日本語訳は こちら。 Source: https://arxiv.org/abs/2608.21755

arXiv:2608.21755v2 Announce Type: replace Abstract: Long-horizon agents require more than retrieval over stored conversations: they must preserve source evidence, revise outdated knowledge, and distinguish relevant memories from sufficient support for an answer. We present ECHO (Embodied Context & History Orchestration), an auditable dual-path memory system. A fast path captures immutable events and serves multi-route recall, while asynchronous workers consolidate experience into revisable state and rebuild derived indexes. Source provenance, temporal authority, and answer realization are explicit boundaries. The service supports original-source packets with evidence-use checks and disables model-based reranking by default. For the latest reported accuracy, the authors confirm mixed retrieved inputs comprising original dialogue and memory summaries, answered by Qwen3-8B with NF4 quantization. In the latest author-supplied five-system aggregate evaluation, ECHO reports 56.27% answer accuracy, 98.04% source Hit@10, 93.58% macro source Recall@5, and 13.92% hallucination flags, with 19.54 ms mean retrieval latency. Its reported accuracy exceeds Mem0 by 4.53 percentage points in this snapshot. The results are descriptive aggregates; matched question-level evaluation and generation latency remain to be established. We separate these observations from earlier published experiments and engineering regressions.
