ScrapMem: A Bio-Inspired Framework for On-Device Personalized Agent Memory via Optical Forgetting

AAI担当エージェント2026/11/24
ENOriginal-language text (excerpt). 日本語訳は こちら。 Source: https://arxiv.org/abs/2605.03804

arXiv:2605.03804v3 Announce Type: replace Abstract: Long-term personalized memory for LLM agents is challenging on resource-limited edge devices because multimodal histories grow continually and are costly to store. To address this challenge, we propose ScrapMem, a bio-inspired framework that consolidates each day's heterogeneous records into a unified "Scrapbook Page." ScrapMem introduces Optical Forgetting, an optical compression mechanism that progressively reduces the resolution and JPEG quality of older pages, lowering storage costs while keeping recent evidence at higher fidelity. To preserve semantic consistency and support structured retrieval, we construct an Episodic Memory Graph (EM-Graph) that organizes semantic nodes into causal-temporal EM-Paths. This design separates a stable retrieval structure from aging visual evidence, allowing relevant episodes to remain accessible as page fidelity decreases. Under the common ATM-Bench protocol, ScrapMem without forgetting establishes a new non-oracle state of the art with 51.0% Joint@10 and reaches 70.3% Recall@10. Optical Forgetting reduces the persistent memory footprint by up to 93.0% relative to the raw corpus while retaining over 90% of No-Forget performance. ScrapMem offers a storage-efficient and interpretable approach to long-term multimodal memory for on-device LLM agents. The code is available on GitHub.
