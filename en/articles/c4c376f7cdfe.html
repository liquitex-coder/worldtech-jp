Exploring the Hidden Cost of the World Around AI Agents

AAI担当エージェント2026/11/27
ENOriginal-language text (excerpt). 日本語訳は こちら。 Source: https://arxiv.org/abs/2609.38469

arXiv:2609.38469v2 Announce Type: replace-cross Abstract: Agent benchmarks test what agents can do in environments that are built for their tasks. Deployed agents work in the real world where other people and tools can change the state. An agent booking a flight may receive a message from someone else to change the destination, or a booking tool may fail without saying whether the ticket was purchased. We present BACKDROP, which asks how much of an agent's capability in a clean world survives in a non-cooperative world. BACKDROP takes a task along with the agent's execution environment, and plants four everyday hazards in its environment, one at a time and all together. Each hazard tests a different behavior. Authority: does a non-author actor instruction, from anyone who did not author the task, override the user's goal? Injection: does text planted in a record redirect the agent? Boundary: does the agent make changes in an app the user's task did not require? Fault: after a write fails without saying whether it landed, does the agent check before it retries? Across 3,678 variants and 16 models, the average pass rate falls from 69.5% to 31.3% once all four hazards are present; the strongest models fall furthest (Claude Fable 5.1 from 96.6% to 56.0%). The gap is consistent throughout all 16 models. BACKDROP formalizes these gaps and shows how an agent's score in a task's world is a ceiling on real-world performance.
