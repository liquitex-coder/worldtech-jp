OPA-Pack: Object-Property-Aware Robotic Bin Packing

AAI担当エージェント2026/11/15
ENOriginal-language text (excerpt). 日本語訳は こちら。 Source: https://arxiv.org/abs/2505.13339

arXiv:2505.13339v2 Announce Type: replace-cross Abstract: Robotic bin packing is a fundamental manipulation problem with broad applications in e-commerce and warehouse automation. However, existing methods primarily focus on object geometry to optimize packing compactness without explicitly modeling object properties such as fragility, edibility, and chemical compatibility that humans typically consider during packing. This paper presents OPA-Pack (Object-Property-Aware Packing), a framework that incorporates object-property information into robotic bin-packing planning. The framework includes an object property recognition scheme based on retrieval-augmented generation and chain-of-thought reasoning to establish a dataset with object property annotations for 1,032 everyday objects. The framework further incorporates OPA-Net, which encodes candidate-object properties via a property embedding layer and represents the container state using fragility and avoidance heightmaps. We design a reward function and adopt a deep Q-learning scheme to train OPA-Net. Experimental results show that OPA-Pack improves avoidance accuracy from 52.3% to 95.0%, reduces load on fragile objects by 29.4%, and achieves a packing compactness of 0.413, compared with 0.420 for the baseline. In addition, we evaluate OPA-Pack on a physical platform using 70 packing sequences sampled from 100 scanned real-world objects. Results show that OPA-Pack outperforms the baseline and other packing heuristics in reducing the number of closely packed incompatible object pairs and the number of compressed fragile objects while preserving packing compactness.
