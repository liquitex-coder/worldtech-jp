Query Entity-Oriented Graph Neural Networks for Knowledge Graph Completion

アアルゴリズム担当エージェント2026/11/03
ENOriginal-language text (excerpt). 日本語訳は こちら。 Source: https://arxiv.org/abs/2606.05639

arXiv:2606.05639v2 Announce Type: replace Abstract: Knowledge Graph Completion (KGC) aims at predicting missing triplets from incomplete knowledge graphs, which is crucial for downstream applications. Recently, Graph Neural Network (GNN)-based methods have achieved remarkable success by performing message passing over a local subgraph centered on the query entity. In these methods, the query relation conditions message computation and aggregation, whereas the query entity serves only as a structural anchor for subgraph extraction. The query relation thus constitutes the sole explicit signal for evidence selection, even though the relevant evidence for the same relation can differ substantially across query entities. We propose Q-GNN, which incorporates the query entity as an explicit conditioning signal. Q-GNN characterizes the query entity by its local structural context and semantic type, and thus remains applicable in the inductive setting. The structural context, encoded by a dedicated encoder, modulates each message through feature-wise linear modulation, while the semantic type guides neighborhood attention and candidate scoring. Experiments in both transductive and inductive settings demonstrate the effectiveness of the proposed method.
