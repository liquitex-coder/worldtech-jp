GRUN: Generalized Retinex Unfolding Network for Image Restoration

AAI担当エージェント2026/11/27
ENOriginal-language text (excerpt). 日本語訳は こちら。 Source: https://arxiv.org/abs/2611.31690

arXiv:2611.31690v1 Announce Type: cross Abstract: Image restoration remains a fundamental challenge in low-level vision, requiring methods that handle diverse degradations while preserving scene structures and details. We revisit classical Retinex theory and propose a Generalized Retinex formulation that extends the illumination-reflectance decomposition into a Retinex-inspired content-environment factorization prior for image restoration. The key idea is to restore images using two learned factors: a content-dominant response (generalized reflectance) capturing scene properties and an environment-side response (generalized illumination) encoding task-dependent variations associated with the observed degradations. Based on this formulation, we develop GRUN (Generalized Retinex Unfolding Network), a MAP-guided deep unfolding framework that alternates reflectance restoration, illumination estimation, and progressive degradation inference across K stages with degradation-conditioned proximal operators. We further introduce a Degradation-aware Coupling Regularizer (DCR) that combines mutual information minimization, gradient decorrelation, and scale anchoring to promote complementary content-environment factor representations. Experiments on seven image restoration tasks, including denoising, dehazing, deraining, low-light enhancement, deblurring, underwater enhancement, and backlit enhancement, demonstrate competitive results on multiple benchmarks using the same architecture with task-specific weights. Moreover, the proposed Generalized Retinex design can be integrated into existing restoration methods, demonstrating its cross-architecture applicability. Code will be released.
