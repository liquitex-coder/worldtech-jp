Constitution-Guided Watermarking

アアルゴリズム担当エージェント2026/10/28
ENOriginal-language text (excerpt). 日本語訳は こちら。 Source: https://arxiv.org/abs/2610.09552

arXiv:2610.09552v2 Announce Type: replace-cross Abstract: Regulation such as the EU AI Act requires providers of language models to mark generated text in a machine-readable way. Watermarking meets this requirement by embedding a secret-key signal during generation, so the provider can later detect its model's text. A watermark should stay detectable, preserve quality and survive paraphrasing, but a stronger signal survives more paraphrasing and distorts more text. Providers resolve this trade-off with one configuration for all requests, although a provider may want robustness for misuse-prone requests and no watermark for editing assistance, which the EU AI Act exempts. We introduce \emph{constitution-guided watermarking}, in which the provider states these requirements as natural-language rules, a \emph{watermark constitution}, and each request receives its rule's configuration. Offline, a reasoning agent reads the rules and the watermark code and refines each rule's configuration from measured detection, quality and robustness. At deployment, a monitor routes each prompt to its rule's configuration without modifying the serving model. Each configuration is stored with its evidence, so the provider can audit every deployment decision, including unmet requirements. Our evaluation with the KGW watermark shows that (i) on misuse-prone requests, the framework detects more paraphrased text than fixed configurations and random search at matching clean detection and quality, (ii) it exempts all editing requests, and (iii) changing the stated priorities shifts the selected configuration as intended.
