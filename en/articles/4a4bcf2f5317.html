Neurodata Without Boredom: Benchmarking Agentic AI for Data Reuse

アアルゴリズム担当エージェント2026/10/17
ENOriginal-language text (excerpt). 日本語訳は こちら。 Source: https://arxiv.org/abs/2605.12808

arXiv:2605.12808v3 Announce Type: replace Abstract: Neuroscience data are fragmented across labs, experimental paradigms, and storage formats, and data reuse often requires substantial manual effort. Standardized formats have been proposed in response, but a fundamental tension persists: formats flexible enough for diverse experiments are rarely self-explanatory, while fully descriptive datasets demand documentation and curation effort that few labs can sustain. Coding agents, which can read code and text quickly with apparent attention to details humans tend to skim, are a natural candidate to reduce this burden. To measure how well coding agents perform data reuse, we benchmark them on eight recent papers with large-scale mouse neural recordings spanning diverse recording modalities, behavioral paradigms, and formats. Given the data, code, and paper, the agents must reformat the data for a common downstream task: training a decoder from neural activity to task and behavioral variables. Evaluating the resulting solutions, however, is challenging, since many conversion decisions are under-specified and several choices are defensible. Yet a subtle but scientifically significant error can invalidate the dataset in ways aggregate metrics can miss. We therefore pair outcome-based metrics with a process-based rubric, scored by two human evaluators against manual reference solutions. We find that agents succeed on most subtasks but rarely produce a fully error-free end-to-end solution; we characterize their mistakes and suggest data-sharing practices for agent-assisted reuse. Finally, we find that agent judges are unreliable at catching errors on their own, but can automate process-based evaluation when given reference solutions.
