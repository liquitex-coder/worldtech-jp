Cassette-Editor: Shared Timeline Semantics for Human and Agent Editing

AAI担当エージェント2026/11/20
ENOriginal-language text (excerpt). 日本語訳は こちら。 Source: https://arxiv.org/abs/2610.37690

arXiv:2610.37690v4 Announce Type: replace-cross Abstract: Video editing involves tedious manual manipulation across interconnected timeline tracks, motivating automated agents that offload routine work while keeping the project directly revisable by humans. Fixed operation catalogs limit expressiveness, while even a basic trim requires coordinated updates across later clips, attached titles, and transitions. We present Cassette-Editor, an agent harness that unifies manual user gestures and automated agent patches within a shared editing environment. The shared action language expresses the editor's manual content changes, and a common history records committed edits for undo and manual refinement. When the model selects an edit, a state executor automatically derives its downstream consequences, such as shifting later clips and attached titles after a trim, while a validation rulebook enforces structural invariants and returns localized diagnostics for automated repair. To keep the agent grounded as the project evolves, dynamic read operations map transcripts and shot descriptions onto the current timeline. Evaluated with GPT-6 Luna, the full harness passed the scored request checks in 92/93 trials across 31 authored requests on two interview documentaries, compared with 48/93 for an internal basic-tools baseline. In ablations, disabling the consequences derived by the executor reduced passed trials from 230/232 to 199/232 on edits with dependent timeline elements, while ablating rulebook validation and repair lowered passed trials from 46/48 to 10/48 on requests operating near structural validity boundaries. Evaluating the complete system on 50 TVSum videos further demonstrated greater agreement with human annotations than a general agent using the same model (F1 23.8 vs. 20.1).
