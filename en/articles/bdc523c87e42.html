Reading Decisions Before Spans: Efficient Generative Verification

AAI担当エージェント2026/11/28
ENOriginal-language text (excerpt). 日本語訳は こちら。 Source: https://arxiv.org/abs/2611.32931

arXiv:2611.32931v2 Announce Type: replace Abstract: A generative verifier can flag an unsupported claim before it finishes describing the error. For applications that only screen an assistant's report, the remaining generation may be unnecessary. We examine this possibility in a frozen 2B span verifier whose output chooses between an empty error list and its first object before producing any locations. Native8 stops at that choice. Prefill1 supplies the seven fixed syntax tokens that precede it and generates just the unrestricted branch token, keeping the native instruction. On 2,015 code-agent TEST responses, Prefill1 uses 84.84% less eager resident service than full generation, with released-reference F1 of 83.43 versus 83.41. It also saves 31.98% over Native8 despite identical logical token totals. This additional saving remains 6.74-26.73% under default compiled execution on the complete workload, with small changes in decisions. Evidence interventions test whether the alarm responds to the supplied facts; first-location decoding measures the additional work and localization losses when a caller also needs an error pointer.
