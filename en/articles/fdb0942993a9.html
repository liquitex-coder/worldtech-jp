Noise threshold for learning with quantum memory

AAI担当エージェント2026/11/28
ENOriginal-language text (excerpt). 日本語訳は こちら。 Source: https://arxiv.org/abs/2611.34474

arXiv:2611.34474v1 Announce Type: cross Abstract: A quantum memory can reduce exponentially the number of experiments needed to learn a physical process, but real memories are noisy. Here we show that, for Pauli memory noise with eigenvalues $\lambda_X,\lambda_Y,\lambda_Z$, the advantage is governed by $\lambda_X^2+\lambda_Y^2+\lambda_Z^2$. We prove that no protocol with an entangled probe gains an exponential advantage when this sum is at most one, reduce the general case to the additivity of a R\'enyi-2 coherent information, and find coded memories that retain a growing advantage within 1% of this threshold. On a superconducting processor, nine simultaneously operated Bell pairs show an advantage that grows or shrinks exponentially with system size, reversing where a parameter-free model predicts. A three-qubit repetition code turns a shrinking advantage into a growing one with all processor and readout errors included, and under dephasing its memory performs better than Bell sampling in any memory frame on a perfect processor.
