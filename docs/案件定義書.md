## 1. 背景・目的

kotaro269.com のような **まとめ／ニュースブログ型サイト** をベースに、独自の価値として
**海外の多言語情報源を収集し、日本語化して届けるニュースメディア**を構築する。

- **テーマ（13カテゴリ）**：サイエンス / AI / テクノロジー / コード / アルゴリズム /
  ロボット技術 / フィジカルAI（身体性AI） / **アート** / **デザイン** / 動画 / 動物 / 自然 / 農業。
- **収集→日本語化**：英語をはじめとする多言語ソース（記事・論文・動画・リポジトリ等）を
  収集し、**日本語へ翻訳**して掲載する。翻訳記事は **原文出典・原言語・翻訳である旨**を
  明示する（権利配慮・信頼）。
- **案件獲得（収益化）**：メディアの信頼・流入を土台に、サイト経由で **3 種**の収益を狙う —
  ①**受託開発**（Web/アプリ/AI 実装）②**翻訳・メディア運用代行** ③**広告・アフィリエイト**。
  ①②は**サービス紹介＋お問い合わせ／依頼 CTA**、③は**広告/アフィリ枠**で実現する。
- **収集ソース 4 型**：①ニュース／ブログ ②論文（arXiv 等）③GitHub／コード ④YouTube／動画。
  各型に専用の記事体裁（標準記事／論文要約／コードブロック／動画埋め込み）を用意する。
- **デザイン基調**：**モダン技術メディア風**（TechCrunch / Hacker News 調 — 余白広め・可読性重視）。
  kotaro269 の情報設計（カード一覧＋サイドバー分類＋ランキング）を踏襲しつつ表層は刷新する。

第一マイルストーンの主目的は「**サイトの見た目（デザイン雛形）をビルド不要の静的 HTML/CSS で
再現し、トップページ・記事ページ・各カテゴリ表現（翻訳出典／コード／動画）・案件獲得導線の
体裁を確定する**」こと。**収集・翻訳の実パイプライン自体は第一段階の done には含めない**
（将来スコープ＝over）。

## 2. スコープと前提

- 第一段階＝**静的デザイン雛形**（試作HTML）。ビルドツール・サーバ不要でブラウザ表示できる。
- コンテンツは当面サンプル記事を流し込み、**収集→翻訳→掲載に載せやすい構造**
  （記事＝タイトル/カテゴリ/サムネ/日付/**原文出典・原言語**/本文/種別[記事·動画·コード]）にしておく。
- 将来段階：多言語収集パイプライン、機械翻訳＋校正、サイト内検索、広告、案件管理（CRM）、SEO 最適化。
- **権利配慮（最重要前提）**：他サイト・多言語ソースを取り込む際は**全文転載せず引用範囲に留め**、
  **原文出典リンクと「翻訳」表示を必須**にする（FR-13 / FR-22 / NFR-4）。
